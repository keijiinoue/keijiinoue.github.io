Security

Learn about our approach to communication and data protection, authentication, and vulnerability response across our industrial drone product line and Fabrikam InsightCloud.

Home / Security

Last updated: July 1, 2026

Scope

The security policies described on this page apply to Fabrikam's entire line of industrial drone products (aircraft, flight control app, and controller) as well as the cloud service "Fabrikam InsightCloud." We protect video, location, temperature, and other data handled during inspection work through multiple layers of protection.

Communication Encryption (NFR-01)

Communication between the aircraft and controller is encrypted using our proprietary transmission method, "Fabrikam Link." Communication between the app/aircraft and the cloud uses TLS encryption. This reduces the risk of eavesdropping or tampering with data in transit.

Data-at-Rest Encryption (NFR-02)

Data stored in Fabrikam InsightCloud is encrypted at rest using a method equivalent to AES-256. Encryption keys are properly managed to prevent unauthorized access to data.

User Authentication & Access Management (NFR-03)

We support user authentication and role-based access control (RBAC), allowing control over the scope of operations and viewing permissions according to organization and role. Multi-factor authentication (MFA) is also supported to prevent unauthorized access through impersonation.

Firmware Authenticity & Secure Updates (NFR-04)

Aircraft firmware is distributed in signed form, and its authenticity is verified at the time of update. Secure boot prevents the execution of tampered firmware. Updates are delivered securely over an encrypted channel.

Operation History & Audit Logs (NFR-05)

Operation history such as logins, data viewing/export, and configuration changes can be recorded as audit logs. These logs can be used to detect unauthorized access and support operational accountability.

Vulnerability Response Policy (NFR-06)

We maintain a dedicated vulnerability intake channel, evaluate reported vulnerabilities, and continuously provide necessary security updates. For significant updates, we publish information such as affected products, workarounds, and response status.

Data Center Physical Security

The data centers that run Fabrikam InsightCloud employ physical safeguards such as access control, surveillance cameras, and redundant power and HVAC systems.

Shared Responsibility Model

We are responsible for the security of the platform and services, while customers are responsible for managing their accounts, configuring permissions, and ensuring appropriate operational handling. Together, we achieve secure operations. For privacy-related handling, please also refer to our Privacy Statement, and for service quality targets, see our SLA.
