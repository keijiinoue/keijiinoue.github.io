Fabrikam InsightCloud Overview

Fabrikam InsightCloud is a cloud platform that centrally manages inspection data, streamlining everything from on-site image capture to report generation.

Captured Data Ingestion

Upload and aggregate visible-light, thermal, and geotagged location data.

Automated Inspection Report Generation

Automatically generate draft inspection reports from captured data, reducing the effort required for report creation.

AI Analysis

AI crack detection and similar features reduce the manual effort of extracting cracks. Final decisions are assumed to be confirmed by a qualified professional.

Change-Over-Time Comparison

Leveraging RTK ±2cm (catalog value) positioning accuracy, time-series comparison of the same location enhances the management of change detection.

Integration via SDK / API

The SDK/API allows integration with existing inspection management and core systems. (FR-21, NFR-25)

  • REST API: Programmatically retrieve and register data, manage jobs, and more.
  • Data Export: Share captured and analyzed data with external systems.
  • Webhooks: Notify external systems of events such as processing completion to automate workflows.

Supported Data Formats

Data can be exported in standard image, video, and point-cloud formats, allowing you to leverage your existing tool assets. (FR-22)

Authentication & Access Control

API integration supports authentication via API keys and OAuth. Combined with user authentication and role-based access control (RBAC), you can configure secure external integrations. For details on encryption, audit logging, and related mechanisms, see Security.

Extensibility

Designed to accommodate future growth in fleet size and features. (NFR-25)

  • Supports scaling up the number of deployed units (from an initial few units to gradual expansion).
  • Multi-tenancy for managing by organization or site.
  • Expanded inspection route templates (feature expansion planned with firmware v1.3, scheduled for release in July 2026).
Specification values related to integration and extensibility are catalog values and may vary depending on configuration and conditions.
